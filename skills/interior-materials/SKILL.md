# 室内设计材质库

> 本 SKILL 为 interior-design 主 SKILL 的子包。**核心职责：任何风格被触发时，如涉及材料，必须给出该风格的「建筑材料 + 家具材料」配方**——禁止只给风格名不给材料。与 interior-styles（风格+配色+灯光三位一体）配合使用：风格触发 = 关键词+配色+灯光+材质四件套。

---

## 一、材质触发规则（强制）

**触发即材质配方**：
- **有风格名**（用户说了风格名，或主 SKILL 联动加载时）→ **自动选中该风格对应行**（如"工业风"→ 第8行），输出三件套：① 建筑材料（地面/墙面/台面/天花）② 家具材料 ③ 来源
- **只有材料词、无风格名**（如"地砖怎么选"）→ 给第三节"材质注意规则"通用要点 + 追问风格："想用哪种风格？我按风格给你具体材料"

**强制原则**：
- 材料必须**具体到材料名**（木材种类/砖类型/石材名），禁止笼统"木质""石材"
- 地面材料重点标注：亮面砖/哑光砖/柔光砖/木纹砖/地板类型（设计师最关注）
- 材料与风格绑定，禁止通用材料表糊弄
- 被主 SKILL 联动触发时与 interior-styles 同步加载，保证四件套（关键词+配色+灯光+材质）一次给全

## 三、材质注意规则（设计师视角）

1. **地面是风格第一识别点**——亮面砖/哑光砖/柔光砖/木纹砖/地板类型必须写准：
   - 奶油风/极简/意式/侘寂 → 柔光砖或微水泥（忌亮面）
   - 北欧/日式/原木 → 浅色原木地板
   - 工业/野兽派 → 水泥自流平/混凝土
   - 欧式/新古典 → 大理石拼花
2. **忌亮面砖**：奶油风/现代美式/复古/野兽派明确忌亮面砖（设计师共识）
3. **木色统一**：原木/日式/侘寂全屋木色 ≤2 种，否则杂乱
4. **金属点缀 ≤2 种**：混搭/轻奢/ArtDeco 金属色（黄铜/黑铁/玫瑰金）不超过两种
5. **材质三要素**（写提示词时）：材质+纹理+行为（见 `[ref:prompt-formula]` 材质体系）
6. 材料表为行业常见归纳，具体到材料名；施工前以当地建材行情为准
7. **与 Style DNA 联动**（v1.0.2）：材质配方与 `[skill:interior-styles]` Style DNA 保持一致——DNA 的 AVOID 字段出现时，材质配方即需检查（如 Modern Minimalist AVOID walnut dominant → 材质配方不主动给胡桃木）；材质选择冲突时以 DNA 为准，向用户提示
