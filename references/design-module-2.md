## 分7 材料决策树 [补充·联网]

### 地面

```
客餐厅：有地暖→柔光大砖 | 宠物→瓷砖/SPC | 温馨→木纹砖
卧室：老人/宝宝→实木复合 | 宠物→SPC石塑 | 预算→强化复合
厨卫/阳台：防滑瓷砖(系数≥0.5)·吸水率≤0.5%
南方潮湿：慎用木地板·优选瓷砖或SPC
```

### 墙面

```
全屋/预算：乳胶漆(VOC≤80g/L·耐擦洗≥6000次)
局部/质感：艺术涂料(背景墙·玄关)
儿童房：可擦洗乳胶漆
宠物：耐擦洗乳胶漆·拒绝墙布
老人：哑光·避免反光
```

### 台面：岩板 vs 石英石

| 场景 | 推荐 |
|------|------|
| 极致性能·热锅直放 | 岩板(SGS认证) |
| 性价比·防渗透 | 石英石(含量≥90%) |
| 儿童家庭 | 石英石(耐画笔) |
| 避免 | 人造大理石(易渗污) |

### 柜门：PET vs 烤漆

| 场景 | 推荐 |
|------|------|
| 易清洁·儿童/宠物 | PET/肤感膜 |
| 质感·轻奢 | 烤漆(怕磕碰) |
| 预算 | 双饰面板 |

## 分8 软装搭配规则 [补充·联网]

### 风格-软装配对

| 风格 | 窗帘 | 地毯 | 挂画 | 抱枕 | 灯具 | 绿植 |
|------|------|------|------|------|------|------|
| 奶油风 | 米杏色绒布 | 羊毛·低饱和 | 简约线条 | 绒面·圆润 | 纸灯·暖光 | 马醉木 |
| 原木风 | 棉麻·米白 | 藤编·剑麻 | 浮世绘 | 棉麻·大地色 | 竹编·和纸 | 琴叶榕 |
| 现代简约 | 百叶·灰 | 纯色·短绒 | 抽象几何 | 纯色·皮革 | 轨道灯·线性 | 龟背竹 |
| 中古风 | 柚木色百叶 | 几何·波斯 | 复古海报 | 皮革·棕调 | 吊灯·黄铜 | 橡皮树 |

### 软装铁律
- 窗帘长度：距地1-2cm·不拖地
- 地毯尺寸：沙发前两腿搭在地毯上
- 挂画中心：距地150-160cm
- 抱枕形状：方圆混搭·不超过3色
- 灯具层次：主灯+落地灯+台灯·至少三层
- 绿植高度：大型落地·中型台面·小型悬挂

## 分9 可维护性检查 [补充·联网]

| 高维护设计 | 问题 | 替代方案 |
|-----------|------|---------|
| 开放格>30% | 积灰·每周擦 | 封闭柜门+10%开放展示 |
| 深色亮面柜门 | 指纹·水渍明显 | 哑光/肤感膜 |
| 微水泥地面 | 易开裂·施工要求极高 | 大规格柔光砖+同色美缝 |
| 白色美缝 | 半年变黄 | 环氧彩砂·灰色系美缝 |
| 玻璃隔断 | 水渍明显 | 长虹玻璃·减少透明面积 |
| 地毯(宠物/儿童) | 藏污纳垢 | 可水洗短绒·或不用 |
| 黑色卫浴五金 | 水垢白斑 | 拉丝镍/枪灰色 |
| 悬空柜(无安装经验) | 安装不稳·脱落风险 | 确认安装师傅专业度 |

## 分10 地域气候适配 [补充·联网]

| 地域 | 策略 |
|------|------|
| 南方潮湿 | 防霉乳胶漆·瓷砖通铺·卫浴加强排风·衣柜离地·除湿机位预留 |
| 北方供暖 | 地暖专用木地板·加湿防木作开裂·窗台石防冷凝水 |

| 低楼层 | 采光补强(浅色+镜面+灯光)·防虫防潮·防盗网不封死 |
| 高层风大 | 推拉窗密封条·窗帘加重·阳台不放大件轻物 |
| 地下室 | 防水防潮优先·新风/除湿机·避免木地板和墙布·排水泵预留 |

## 分11 家庭场景适配 [补充·联网]

### 适老化

地面：全屋无障碍·无门槛石·防滑系数≥0.5
卫浴：淋浴椅·扶手(距地75cm)·坐式淋浴·紧急呼叫位
灯光：夜灯系统·开关距地90cm(轮椅可及)
柜体：圆角·内嵌拉手·低处储物

### 儿童家庭

安全：窗户限位器·插座保护盖·圆角家具·无玻璃茶几
材料：ENF级环保板材·可擦洗墙面
成长：可变家具·学习区可调照明·充足玩具收纳
设计：儿童区地面软质·门防夹手

### 宠物家庭

地面：瓷砖/SPC·放弃实木地板
沙发：科技布/皮质·可拆洗·放弃布艺
柜门：PET/肤感膜·抗刮擦
其他：猫砂盆位·宠物门洞·扫地机器人动线·除味通风

## 分12 设计取舍原则 [补充·联网]

冲突时有优先级：

1. **安全**（承重墙·防水·电气·燃气·防滑）
2. **基础功能**（水电·通风·采光·厨卫）
3. **动线舒适**（不绕路·不碰撞·不压抑）
4. **收纳效率**（高频顺手·低频隐藏·顶天立地）
5. **耐用易维护**（抗污·耐刮·易清洁）
6. **预算控制**（硬装保质量·软装可后期补）
7. **风格美观**（好看但不牺牲以上任何一项）

### 常见冲突速裁

| 冲突 | 建议 |
|------|------|
| 开放式厨房 vs 油烟 | 移门/中西厨分离 |
| 浴缸 vs 淋浴 | 单卫选淋浴·双卫主卫可考虑 |
| 收纳 vs 通透 | 封闭柜为主·玻璃门展示为辅 |
| 无主灯 vs 层高 | 层高<2.7m不做全吊顶·选明装射灯 |
| 双台盆 vs 储物 | 单卫选储物·双卫主卫可双台盆 |

## 分13 多方案对比 [补充·原创]

用户需求不明确时，输出3方向：

| | 方案A·保守实用 | 方案B·颜值提升 | 方案C·收纳强化 |
|------|------|------|------|
| 优点 | 预算可控·不易翻车 | 设计感强·适合社交 | 空间利用率高 |
| 缺点 | 可能平淡 | 预算高·维护成本高 | 可能牺牲通透 |
| 适合 | 首次装修·预算紧 | 有审美追求·预算宽 | 物品多·有孩家庭 |
| 风险 | 低 | 中 | 中 |

## 分14 灯光深化 [补充·联网]

每个空间三要素：

| 空间 | 主照明 | 重点照明 | 氛围照明 |
|------|--------|---------|---------|
| 客厅 | 轨道灯/吸顶灯 | 电视墙洗墙灯·挂画射灯 | 落地灯·灯带 |
| 卧室 | 吸顶灯(可调光) | 床头阅读灯 | 床下感应灯 |
| 厨房 | 平板灯 | 吊柜下方操作台灯·水槽灯 | 抽屉内灯 |
| 卫生间 | 镜前灯(左右布·不顶布) | 淋浴区防水灯 | 夜灯 |

关键数据：色温统一(同空间≤500K差)·显色Ra≥90·防眩UGR<19·开关独立回路

## 分16 风格决策引导 [补充·原创]

用户犹豫时·用5问替代直接科普：

1. 喜欢温暖还是清爽？
2. 采光好不好？（采光差避深色系）
3. 能否接受白色打理？（奶油风·白色需维护）
4. 有无小孩宠物？（影响材料选择）
5. 预算偏紧还是充足？（极简/侘寂预算要求高）

## 分17 房屋状态识别 [补充·联网]

AI先判断房屋状态：

| 状态 | 策略核心 |
|------|---------|
| 毛坯房 | 从零系统规划·水电·墙体·吊顶·材料 |
| 精装房 | 少拆少改·保留可用·软装+局部提升·不破坏防水地暖 |
| 二手房局改 | 优先水电安全·厨卫翻新·其他保留 |
| 老房全改 | 管线老化优先·墙体空鼓·防水重做·门窗更换·结构安全 |
| 出租房 | 耐用·低成本·易维护·标准件 |

## 分19 设计伦理与责任边界 [补充·原创]

AI不得：
- 建议拆除承重墙
- 建议私改燃气主管
- 建议改变建筑外立面且不提示审批
- 建议封堵消防通道
- 对结构安全作确定性承诺
- 对防水/电气/燃气施工给出替代专业人员的最终判断
- 替代注册建筑师/结构工程师/持证电工

涉及结构/燃气/消防/大面积防水时·方案中必须标注：`[需专业人员现场确认]`

## 分20 商业/办公空间边界 [补充·原创]

当前版本定位：**住宅家装**。商业/办公仅提供概念建议·不提供完整落地方案。如需商业空间设计·建议使用专业工装设计工具。
