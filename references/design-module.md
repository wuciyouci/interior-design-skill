# 设计深化模块 [v6.5新增]

> 来源：联网搜索·GB 55038-2025·行业通行实践。框架化补充分1~分6。

## 分1 户型图诊断 [补充·联网]

### 诊断流程

用户上传/描述户型时，按序输出：
1. 户型识别结果（几室几厅·朝向·层数）
2. 承重墙/非承重墙识别（黑色实心线=承重·绝不建议拆）
3. 动线分析（访客·家务·动静分区）
4. 采光分析（明厨明卫？窗户位置？有无暗室）
5. 通风分析（南北通透/相邻通风/单面采光）
6. 户型优点（3-5条）
7. 户型问题（3-5条·按严重度排序）
8. 可改造点（非承重墙拆除/空间重组）
9. 不可贸然改造点（承重墙/配重墙/管井/烟道）
10. 需物业/现场确认的问题

### 承重墙判断

| 图纸标记 | 含义 | 可拆？ |
|---------|------|--------|
| 黑色实心粗线 | 承重墙/承重柱 | ❌ 绝不 |
| 白色/浅色填充 | 非承重墙 | ⚠️ 需物业确认后酌情 |
| 阳台与客厅间短墙 | 配重墙 | ❌ 不拆 |

⚠️ 涉及墙体改造时必须额外追问："请确认该墙体是否为承重墙？建议向物业查阅户型结构图确认。"（硬规则7）

## 分2 空间问题诊断库 [补充·联网]

### 客厅显小
原因：家具比例过大·电视墙造型复杂·收纳外露·色彩对比过强
策略：低矮家具·轻体量茶几·浅色大面·同色系柜体·墙顶地减少分割·洗墙间接光

### 玄关无鞋柜
策略：超薄鞋柜(17-20cm)·侧墙洞洞板·换鞋凳结合收纳·餐边柜兼鞋柜·走廊尽端柜

### 厨房太暗
策略：拆改与餐厅间非承重墙用玻璃推拉门·吊柜下方加灯带·浅色台面墙面·增加柜内灯

### 卫生间太小
策略：洗手台外置(需确认非承重墙)·壁挂马桶节省空间·淋浴区用浴帘代替玻璃隔断·镜柜收纳

### 卧室放不下衣柜
策略：床靠墙放·床头柜换成小边几·衣柜做到顶·用推拉门代替平开门·床底增加抽屉收纳

### 采光差
策略：浅色装修·镜面反射·减少实体隔断·玻璃门/半墙·灯光分区补光·避免深色大面积使用

### 层高低
策略：不做吊顶·灯具选吸顶/半吸顶·避免复杂吊灯·窗帘盒尽量简洁·竖向线条拉伸视觉

## 分3 全屋收纳系统 [补充·联网]

### 按物品分类

| 物品类别 | 建议存放位置 | 柜体深度 |
|---------|------------|---------|
| 鞋靴 | 玄关鞋柜 | 35-40cm |
| 外套 | 玄关挂衣区/卧室衣柜 | 55-60cm |
| 清洁工具 | 阳台/卫生间/家政柜 | 30-40cm |
| 行李箱 | 卧室衣柜顶部/储物间 | ≥60cm |
| 换季衣物被褥 | 衣柜顶部/榻榻米/床箱 | 55-60cm |
| 书籍 | 客厅/书房·开放或玻璃门 | 30-35cm |
| 玩具 | 客厅矮柜/儿童房 | 30-40cm |
| 药品 | 客厅/卧室抽屉·高处防儿童 | 15-20cm |
| 小家电 | 厨房高柜/餐边柜 | 40-45cm |
| 食品囤货 | 厨房高柜/储物间·离地防潮 | 30-40cm |
| 洗护用品 | 卫生间镜柜/浴室柜 | 15-20cm |
| 宠物用品 | 玄关/阳台/客厅宠物区 | 30-40cm |

### 收纳铁律

- 高频物品放黄金高度(腰到眼)·低频物品放高处或深处
- 柜体顶天立地·减少落灰死角
- 开放格≤总柜体的20%·其余做门板
- 每个空间至少留一个"随手放"台面
- 收纳需要可视化——打开柜门一眼能看到所有东西

## 分4 水电点位建议 [补充·联网·参考 GB 55038-2025]

### 各空间点位速查

**客厅：** 电视墙4-6个(隐藏式)·沙发两侧各1个(含USB)·空调16A·扫地机器人低位·投影/音响按需

**卧室：** 床头两侧各1-2个(含USB+双控)·书桌/梳妆台2个·空调16A

**厨房：** 台面上方≥5个(带开关·防溅盒)·水槽下方2个(净水器/垃圾处理器)·冰箱独立回路·灶具下方严禁设插座

**卫生间：** 镜柜旁1-2个(防溅型·防水盒)·智能马桶低位·电热水器/浴霸独立4mm²回路·插座距淋浴区≥1.5m

**阳台：** 洗衣机·烘干机各1个(高于进水口)

### 关键数据

| 项目 | 标准 |
|------|------|
| 普通插座距地 | 30cm |
| 开关距地 | 130cm |
| 厨房台面插座距台面 | 30cm |
| 空调插座距地 | 180-220cm |
| 强弱电间距 | ≥30cm |
| 卫生间插座防水等级 | IP54或加防水盒 |

> ⚠️ 水电点位仅作前期规划建议，最终需由专业电工根据现场和规范确认施工。

## 分5 施工验收清单 [补充·联网]

### 各阶段检查

**拆改阶段：** 是否确认承重墙·是否保护下水口·是否保留原始管线照片

**水电阶段：** 电线分色·强弱电间距≥30cm·水管打压0.8MPa保压30min·插座位置与家具不冲突·插座回路均含漏保(RCD≤30mA·GB 55038-2025)

**泥瓦阶段：** 防水高度(淋浴≥1.8m·其他≥1.5m)·闭水试验24h·瓷砖空鼓率≤5%·地漏坡度

**木作阶段：** 柜体垂直度·封边质量·柜门缝隙均匀·五金顺滑度

**油漆阶段：** 墙面平整度·阴阳角垂直·无色差·无开裂

**安装阶段：** 洁具打胶饱满·门套收口严密·灯具测试·插座通电测试

## 分6 交付深度分级 [补充·原创]

### 输出前判断用户需求深度

| 级别 | 适用场景 | 输出内容 |
|------|---------|---------|
| L1 灵感建议 | "帮我看看这个风格"·"给我点灵感" | 风格·配色·材质·AI生图提示词 |
| L2 初步方案 | "我家XX㎡想装修" | L1+空间布局·功能分区·收纳方向·预算比例 |
| L3 深化方案 | "帮我把方案做细" | L2+尺寸校核·灯光系统·材料系统·水电点位·收纳落位 |
| L4 施工辅助 | "准备开工了" | L3+施工顺序·验收重点·避坑清单·现场确认项 |

AI根据用户提问内容自动判断深度级别，并在方案开头标注：`[交付深度：L2]`。未明确时默认L2。
