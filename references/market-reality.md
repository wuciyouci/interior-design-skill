# 室内 28 风格·市场实况速查表

> 数据来源：2026-08-17 五平台搜索结果（欧模网 om.cn / 小红书含官方月报 / 知末网 znzmo.com / 3d溜溜网 3d66.com / 建E网 justeasy.cn），全部来自真实素材/案例/笔记标题与内容。
> 用途：对照 interior-styles SKILL 教科书配方，校准市场真实搭配。

## 〇、跨风格市场通用语言（教科书缺失，市场高频）

| 维度 | 市场通用做法 |
|---|---|
| 灯光 | **无主灯是跨所有风格的默认灯光语言**（筒射灯+磁吸轨道+线性灯带组合）；双眼皮吊顶（层高≥2.6m）；"见光不见灯"；小红书主流 2700-3000K 暖光 |
| 配色 | **高级灰**（轻奢/意式/极简标志色）；乳胶漆色号话语（可可蛋奶/珍珠白/菱花白/汝窑/杏子灰/布莱垦棕）；美拉德配色（复古系：焦糖/卡其/深浅棕） |
| 材质 | 岩板（轻奢/意式核心）、微水泥（侘寂代名词）、PU线条+虎头石膏线（法式）、长虹玻璃、肤感哑光柜体、木纹砖平替木地板（省钱）、鱼骨拼/人字拼 |
| 结构 | 精装房改造（软装换风格）、去客厅化、LDK一体化、门墙柜一体化、岛台+餐厨一体 |
| 命名 | **市场无"纯风格"，全是"基座+后缀"组合**：现代X、奶油X、X轻奢、XX复古 |

## 一、超火 TOP 风格（7 个）

### 1. 现代简约（万能基座"现代"）
| 维度 | 市场实况 |
|---|---|
| 调色 | 黑白灰+高级灰；但建E网案例强调"原木暖色融入，非纯冷淡" |
| 灯光 | 无主灯（筒灯/射灯+磁吸轨道+线性灯组合）、双眼皮吊顶、2700-3000K |
| 材质 | 岩板通铺、嵌入式家电、肤感柜体 |
| 其他 | "现代+XX"叠加为常态（现代轻奢/现代意式/现代奶油）；去客厅化；悬浮电视柜 |

### 2. 中古风（2025 小红书双榜 TOP1）
| 维度 | 市场实况 |
|---|---|
| 调色 | 50%白墙+30%胡桃木+奶咖/中灰墙面；酒红色地毯压冷感；黑色中古/黑白中古变体 |
| 灯光 | 3000-3500K；明装射灯/吊灯/氛围灯；**不要水晶灯**；黄铜落地灯 |
| 材质 | **胡桃木+骨骼线柜门+洞石+鱼骨拼+玻璃砖+风扇灯**（教科书缺的标志元素）；木纹砖 600×1200 通铺不做过门石；弧形柜角；黄铜 |
| 其他 | 精装房改造首选；最强融合=法式中古；中古奶油；暖调深木为灵魂 |

### 3. 法式风（主流=法式奶油/轻法式）
| 维度 | 市场实况 |
|---|---|
| 调色 | 奶油白/菱花白乳胶漆墙顶通刷；莫兰迪色系点缀 |
| 灯光 | 3000K 暖光；重点照明+氛围灯 |
| 材质 | PU线条背景墙/虎头石膏线+双眼皮边吊；R200 圆弧造型/拱形门洞；**人字拼木地板**；丝绒+大理石+黄铜（"3+2"必选法则）；玻璃门餐边柜+黄铜把手 |
| 其他 | 轻法式=去雕花去罗马柱（小户型）；法式奶油=最大爆款融合；法式中古=欧模网最强融合标签；宫廷法式基本退场 |

### 4. 奶油风（万能底色，爆款 TOP1）
| 维度 | 市场实况 |
|---|---|
| 调色 | 乳胶漆色号：可可蛋奶/珍珠白/菱花白/汝窑/杏子灰/布莱垦棕；60%主色+30%辅助+10-20%点缀 |
| 灯光 | 无主灯+2700-3000K 暖光；云朵灯/花朵吊灯 |
| 材质 | 肤感哑光柜体、羊羔绒/绒布沙发、亚麻窗帘、圆角家具 |
| 其他 | **必须深色/黑色压底防腻**（教科书没提）；白色过多显冷；预算低变"廉价出租屋风"；强势进商业（SPA/酒店大堂）；与原木绑定成"奶油原木" |

### 5. 意式极简（主流词=意式轻奢）
| 维度 | 市场实况 |
|---|---|
| 调色 | 纯白软装+冷调奢石+深黑柜体三角配色；高级灰 |
| 灯光 | **无主灯+灯带是灵魂**（格栅灯带/悬浮顶灯带/柜内灯带，3000K 暖光） |
| 材质 | 门墙柜一体化（同色同纹同工艺）；**哑光烤漆优于亮面**；岩板/木格栅；碳熏木饰面+微水泥+仿石砖；岛台+餐厨一体；Minotti/Poliform 品牌家具语言 |
| 其他 | "极简=70%隐藏+30%留白"；适合常住≤2人、衣物<150件；与轻奢强绑定（意式轻奢才是主流词） |

### 6. 新中式（主流=宋式美学）
| 维度 | 市场实况 |
|---|---|
| 调色 | 沉稳深木色+浅灰沙发张力；水墨/山水元素；暖白自然光影 |
| 灯光 | 暖白自然光影为主；3000K；长条形壁灯 |
| 材质 | 大理石+原木+皮质；铜制五金；山水屏风/薄纱刺绣（喜上眉梢纹样）；宋式木金属屏风 |
| 其他 | **"宋式美学"是平台当前最大热词**（知末网新中式轻奢客厅 1433 模型=全站最大单点）；慎用红木（显老气）；水移画/水性漆 DIY 改色；新中式×轻奢、新中式×侘寂、新中式+欧式混搭（+320%） |

### 7. 原木风（主流=奶油原木）
| 维度 | 市场实况 |
|---|---|
| 调色 | 暖白"奶一点"的墙漆；材质比例"原木35%+石材15%+织物50%" |
| 灯光 | 中性偏亮、1:1 冷暖比；3000-3500K |
| 材质 | FAS级橡木/白蜡木；浅木色通顶柜无缝衔接；木饰面**局部点缀**而非大面积铺；水泥砖通铺 |
| 其他 | "原木奶油"已成固定组合词；性价比担当、小户型首选；避深色原木小户型（层高视觉降15cm）；潮湿地区别全屋实木；避开颗粒板 |

## 二、主流风格（8 个）

### 8. 轻奢风（万能后缀，不是独立风格）
| 维度 | 市场实况 |
|---|---|
| 调色 | 高级灰+香槟金；雾霾蓝+奶油白+香槟金 |
| 灯光 | 3000K 暖光+线性灯带；无主灯 |
| 材质 | **岩板+金属=王炸组合**（岩板台面+金属线条吊顶+黄铜开关面板）；岩板选购：光泽度≥4级、厚度≥15mm；奢石 |
| 其他 | 全部以"XX轻奢"形态出现（法式/奶油/港式/新中式/美式/意式/后现代/老钱风）；"现代轻奢"≈标准前缀；靠材质不靠金色堆砌 |

### 9. 北欧风（几乎不单独出现）
| 维度 | 市场实况 |
|---|---|
| 调色 | 莫兰迪灰+雾霾蓝+焦糖棕+奶咖（6:3:1）；森林系公式：30%自然材质+40%柔和色调+30%绿植 |
| 灯光 | 自然光为主；"光照不足也明亮柔和" |
| 材质 | 原木+布艺+藤编+收纳柜；品牌化设计（Mim Design 等）；黄铜把手点缀 |
| 其他 | 主流="文艺复古北欧"（30%复古+50%北欧+20%艺术）；纯北欧被批"滤镜疲劳"；绿植：龟背竹/琴叶榕/虎皮兰；建E网纠偏"北欧才不是性冷淡" |

### 10. 侘寂风（=微水泥代名词）
| 维度 | 市场实况 |
|---|---|
| 调色 | 大地色系（米白/咖/棕/炭黑） |
| 灯光 | 2700K 低照度暖光；纸灯/藤编灯 |
| 材质 | **微水泥/艺术涂料墙地一体**（最大翻车点：开裂/贵/难打理；"20万全屋微水泥半年开裂"→先做1㎡小样、卫生间地面用瓷砖）；实木/粗陶/麻织/藤编；旧实木椅+麻质椅套 |
| 其他 | "新侘寂"=去破旧+现代精致；常与中古/奶油/日式/禅意四向融合；建E网：侘寂是精神内核不是材质配方 |

### 11. 美式风（主流=简美/小美式）
| 维度 | 市场实况 |
|---|---|
| 调色 | 70%中性色打底+30%复古点缀（墨绿/酒红/芥末黄） |
| 灯光 | 壁炉+无主灯；台灯+落地灯组合 |
| 材质 | 橡木地板色系（暖棕橡/咖啡白橡/烟熏橡，浅色系小户型显大）；皮质+丝绒+黄铜五金；**踢脚线15cm**；百叶窗 |
| 其他 | 小美式 3 个月暴涨 240%；美式复古 +178%；"现代美式轻奢小法式"三重融合；经典美式混搭现代/北欧 7:3（解决"美式土味感"） |

### 12. 日式风（≈原木风+榻榻米+茶室）
| 维度 | 市场实况 |
|---|---|
| 调色 | 原木+留白；原木色占比≥60% |
| 灯光 | 3000K 全屋暖光+纸灯/藤编吊灯 |
| 材质 | 藤编点缀（约20%）；榻榻米（离地15cm 地台）；壁龛收纳；木质包覆天花+架高地坪 |
| 其他 | 榻榻米="60%储物+40%休憩"（收纳+一室多用）；障碍纸/枯山水教科书元素基本退场；日料亭厨房；与"奶油原木"高度重叠 |

### 13. 极简主义（已溶解进意式极简/侘寂）
| 维度 | 市场实况 |
|---|---|
| 调色 | 灰白+原木（搜索最高）；奶咖+水泥灰；深蓝+浅灰 |
| 灯光 | 无主灯 |
| 材质 | 莫兰迪+原木=高级感密码 |
| 其他 | 主流形态="意式极简/极简美式/极简北欧/原木极简"复合标签；10万预算攻略（软装40%+硬装35%+预留25%）；宜家基础款省30% |

### 14. 复古风（"复古"是形容词不是风格名词）
| 维度 | 市场实况 |
|---|---|
| 调色 | **美拉德配色**（焦糖/卡其/深浅棕+橘红点缀）；60年代风（奶油白+驼色+墨绿酒红+琥珀金） |
| 灯光 | 2700-3000K 暖光；铁艺吊灯；爱迪生灯丝 |
| 材质 | 做旧家具、老式收音机、二手市场淘货、复古花砖、钨丝灯泡 |
| 其他 | 永远以"法式复古/美式复古/工业复古/中古复古"定语出现；复古北欧被称为"最火风格之一" |

### 15. 现代港式（=港式轻奢）
| 维度 | 市场实况 |
|---|---|
| 调色 | 灰+咖硬装+**爱马仕橙和金属色点缀**；雾霾蓝+燕麦米+勃艮第红配色公式 |
| 灯光 | 无主灯+大理石背景；金属/水晶吊灯 |
| 材质 | 雀眼木饰面+皮革硬包+不锈钢；镂空金属隔断；微水泥地面；复古红绿丝绒沙发+粤式怀旧玻璃酒柜（港片氛围） |
| 其他 | **精装房交付默认风格**；哑光墙面约70%；茶餐厅是商业活场景；出现"老钱风"新标签 |

## 三、小众/转型风格（6 个）

### 16. 工业风（主战场=餐饮工装）
| 维度 | 市场实况 |
|---|---|

### 20. 混搭风（组合标签，非风格）

|---|---|

## 四、基本无市场风格（6 个，建议降级/移除或改定位）

### 23. ArtDeco —— 建议移除
- 调色：黑+金强对比；蓝金轻奢对称纹样；红棕+黑+金
- 材质：柚木通铺+黄铜+奢石岛台；几何拼花地砖+骨骼线门板
- 市场现状：欧模网零分类；知末网仅屏风/柱子构件；3d溜溜仅3条（含高层住宅建筑立面）；小红书无专属热度
- 残留场景：高层住宅立面/规划、轻奢软装纹样（装饰画）

### 24. 波西米亚 —— 建议降级为软装元素层
- 调色：米白基底+雾霾蓝/焦糖棕/陶土粉+琥珀金点缀；莫兰迪绿+雾霾蓝+焦糖棕占比>65%；避雷纯白/克莱因蓝/荧光色
- 灯光：藤编吊灯/纸灯 2700K；串灯
- 材质：藤编×皮质×亚麻×金属 4:3:2；扎染流苏手工编织；复古民族风花砖；装饰品总数8-12件以内
- 市场现状：归"民族风"分类；只以地毯/挂毯/饰品存在；场景=民宿/出租屋/商业；卧室主题爆火；DIY搜索暴涨230%

### 25. 赛博朋克 —— 建议改为"商业空间主题"
- 调色：冷色≤3种；霓虹紫蓝
- 灯光：4000-6000K 冷色线性灯带隐藏+磨砂扩散罩；"光线控制而非堆砌"
- 材质：金属线条/镜面金属墙/黑色磨砂钢板/亚克力；金属≤40%；勿用塑料感霓虹灯
- 市场现状：酒吧/夜市/剧本杀/奶茶店/步行街；本土特色"国潮赛博朋克""新中式与赛博朋克"；小红书存在感=AI效果图爆款（6.9万赞）非实装

### 26. 沙漠风 —— 建议降级
- 调色：大地色系+沙土造型+洞穴感；《沙丘》废土美学
- 材质：微水泥通铺天地墙（西班牙萨玛赫，卡戴珊同款）；弧形"从地上长出来的"浴缸
- 市场现状：家装概念不存在；全是建筑外观/庭院/民宿（沙迦 Al Faya Lodge 案例）；小红书仅获奖案例级内容

### 27. 野兽派 —— 建议移除
- 调色：水泥灰+原木+金属；粉色水泥墙案例（调20多种粉定"灰玫瑰粉"做颗粒肌理）
- 材质：水泥墙+做旧金属+原木家具"高级感三重奏"；肌理漆墙面
- 灯光：2700K 暖光为主
- 市场现状：3d溜溜仅1条清水混凝土立面灵感图；小红书存在感被鲜花品牌"野兽派"混淆；唯一案例是商业店（成都太古里）

### 28. 现代农舍 —— 建议移除
- 调色：纯白外立面+黄延窗框
- 材质：弧形壁炉+旧物改造；木板墙
- 市场现状：家装概念不存在；实际形态=小红书乡村自建房/老宅改造（"旧鸡房改梦中情屋"30万案例）+民宿外观；四平台均无此分类
