# 室内设计AI工作流 Skill 包 · 安装使用指南

## 这个技能能做什么

一套完整的**室内设计 AI 工作流**——不是零散提示词，是「28 种风格 + 硬规则 + 审计脚本」的工程化体系。

- **28 种风格配方**：每种风格含「关键词 + 配色(60/30/10) + 灯光(色温K/主光/补光) + 材质」四件套，直接可拿去生图/选材
- **8 条硬规则**：禁止估算尺寸 · 预算只做比例拆分不报价 · 涉及拆墙必确认承重墙 · 禁止编造朝向/相邻关系……违反即无效输出
- **风格漂移检测**：多个核心特征同时偏移时告警，防止 AI 出图变"四不像"（含高风险漂移对表）
- **跨规则一致性矩阵**：Style×Color×Material×Lighting×Furniture×Decor 八对检查，冲突按优先级自动裁决
- **户型图驱动设计**：识别 → 确认 → 诊断 → 方案ABC 完整流程，不瞎编承重墙
- **白模转写实效果图**：FLUX2「锁定布局 + 换风格」提示词公式（AI 生图核心链路）
- **光源可追溯 + 材质保真 + 负面词三层体系**：解决"光从哪来说不清""材质张冠李戴""AI 出幻觉"
- **附可执行脚本**：`audit.py`（提示词一致性审计 PASS/WARN/FAIL）+ `verify_layout.py`（Blender 白模布局校验）

## 适用工具

ChatGPT（GPT-4/4o/5）·Claude（Claude Code/Project）·Kimi·豆包·DeepSeek

## 安装方法

### Claude Code

1. 将整个文件夹放到 `~/.claude/skills/interior-design/`
2. 重启 Claude Code·自动识别

### ChatGPT / Kimi / 豆包 / DeepSeek

1. 打开 `SKILL.md`·全选复制
2. 粘贴到**自定义GPT/助手设置**的"系统提示词/Instructions"框中
3. 保存·新建对话即可使用

### 普通聊天窗口

1. 复制 `SKILL.md` 全部内容
2. 粘贴到聊天框·加一句"请按以上规则执行"
3. AI确认后即可开始输入需求

## 快速开始

在对话中说：

> 我家89㎡三室一厅，常住夫妻二人和一个孩子，想装原木风，预算档位偏经济，没有户型图。

或者使用新手模板（在 SKILL.md 末尾）：

```
我家是____㎡，____室____厅____卫，常住____人。
想要____风格，重点需求是____。
预算档位：经济 / 舒适 / 高端。
是否有户型图：有 / 没有。
```

## 生成效果图

1. AI输出方案中会包含英文AI生图提示词
2. 将提示词复制到 Midjourney / 豆包 / 即梦 / DALL-E 3 等工具
3. 如需控制构图和结构：使用 Stable Diffusion + ControlNet
